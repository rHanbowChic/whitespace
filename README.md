## whitespace

**whitespace**是一个加密笔记映射协议。它使用“命名空间+页面”的模型，将笔记映射到真实URL，并对内容进行加密。

被映射到的URL均为64位，由[0-9a-f]组成。例如,域名`note.ms`上命名空间“0”的“0”页面会映射到`note.ms/6368f4d889426d21b909175bb5f0adf12b345fb5c3d05006ad6cbc954c66c8f5`。

对于内容，whitespace使用AES-256-GCM算法加密，并以base64格式存储。对比原文档仅有1/4的空间损耗。

whitespace默认使用一个很高的密钥迭代次数（16383次）生成页面映射与加密密钥。此密钥与命名空间，页面名与当前域名有关。

### 亮点

* 高密钥迭代次数，防止建表攻击。这个特性确保了只要命名空间或页面名难以猜测，**即使拥有后端权限的人也无法得知whitespace上存了什么**。
* 支持字节流。这意味着whitespace可**存储任何文件类型**，不仅仅是文本文档。
* 多命名空间。使用你的命名空间，你可以拥有一个只属于自己的笔记本。
* 可调密钥迭代深度。更深的空间对破解防御性更高，且难以被广域覆盖。
* 丰富的平台支持（.NET，Python，JavaScript（WASM））
